### 🗃️🌐 Public Dataset Repositories for Experiments

Below is a curated list of high-quality public dataset repositories to conduct experiments, train models, and study Data Science and Machine Learning techniques:

| Repository / Platform | Description | Link |
| :--- | :--- | :--- |
| **Kaggle Datasets** | Thousands of community-published datasets and data science competitions covering almost every domain. | [Access](https://www.kaggle.com/datasets) |
| **Portal Brasileiro de Dados Abertos** | Official Brazilian government open data portal containing data on economy, education, health, and public administration. | [Access](https://dados.gov.br/home) |
| **UCI Machine Learning Repository** | One of the oldest and most famous repositories in the ML community, ideal for benchmarking algorithms. | [Access](https://archive.ics.uci.edu/datasets) |
| **Hugging Face Datasets** | Huge collection of state-of-the-art datasets hub, primarily focused on NLP, Audio, Computer Vision, and Multimodal tasks. | [Access](https://huggingface.co/datasets) |
| **Google Dataset Search** | A comprehensive search engine by Google that helps find datasets stored across thousands of repositories on the web. | [Access](https://datasetsearch.research.google.com/) |
| **AWS Open Data Registry** | Large-scale public datasets available on Amazon Web Services, including genomics, satellite imagery, and climate data. | [Access](https://registry.opendata.aws/) |
| **Our World in Data** | Excellent resource for global trend data regarding poverty, health, energy, environment, and demographics. | [Access](https://ourworldindata.org/) |
| **FiveThirtyEight** | Cleaned and ready-to-use datasets used in political, cultural, and sports journalism. | [Access](https://github.com/fivethirtyeight/data) |
| **Zenodo** | A general-purpose open-access repository developed under the European OpenAIRE program, hosting research data. | [Access](https://zenodo.org/) |
| **Awesome Public Datasets** | A high-quality, community-maintained list of public datasets categorized by topic on GitHub. | [Access](https://github.com/awesomedata/awesome-public-datasets) |
